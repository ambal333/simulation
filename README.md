# Simulation

[![Python](https://img.shields.io/badge/Python-3.x-blue.svg)](https://www.python.org/)
[![GitHub](https://img.shields.io/badge/Source-GitHub-black.svg)](https://github.com/ambal333/simulation)

Симуляция экосистемы на двумерной карте. В мире размещаются природные объекты, травоядные и хищники. Симуляция запускается с заданным начальным состоянием, а затем выполняет действия на каждом ходу.

Проект демонстрирует объектно-ориентированную организацию симуляции, разделение логики на классы и визуальное отображение состояния карты.

## Ключевые особенности

- **Двумерная карта** — создание игрового мира с заданными размерами.
- **Природные объекты** — размещение камней, деревьев и травы.
- **Травоядные** — создание существ, питающихся растительностью.
- **Хищники** — добавление хищников в экосистему.
- **Система ходов** — выполнение заданных действий в процессе симуляции.
- **Визуализация** — отображение состояния карты с помощью `Renderer`.
- **Модульная архитектура** — разделение логики симуляции, карты и действий по отдельным классам.

## Принцип работы

1. Создаёт карту размером `10 × 10`.
2. Создаёт объект `Renderer`, связанный с картой.
3. Формирует список `init_action` — начальные действия для размещения объектов и существ.
4. Формирует список `turn_action` — действия, выполняемые на каждом ходу.
5. Создаёт объект `Simulation`, передавая ему карту, оба списка действий и визуализатор.
6. Запускает симуляцию методом `start_simulation()`.
